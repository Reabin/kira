# iPhone 自用构建

iOS 使用与 Android 相同的 `lib/`、资源及依赖，包含当前漫画和轻小说功能。
最低系统版本为 iOS 14（文件选择插件要求）。
本适配基于上游 `fc3f242fee2e3b68de94bc35296fc73db60031c3`（1.7.2+509）。

## 在 Windows 上取得 IPA

1. 在自己的 Fork 中打开 Actions，若提示工作流未启用，启用它们。
2. 选择 **Build iOS IPA**，点击 **Run workflow**，选择包含适配的分支。
3. 成功后下载 `kira-ios-unsigned` artifact，解压取得 IPA。
4. 用 Windows AltServer / AltStore Classic 和自己的 Apple 账号重新签名安装。
   IPA 未签名，不能直接点击安装。普通免费账号需要定期刷新签名。

工作流使用 macOS、Xcode 26.3、Flutter 3.44.2 和 CocoaPods，先进行静态检查及相关测试，
再编译真机 Release 应用。不会上传 Apple 账号、证书或发布 App Store。

## iOS 平台行为

- 保存图片时请求相册访问权限，图片放入 kira 相簿。
- 漫画及小说详情在 iOS 使用 Cupertino 路由，支持从左侧边缘滑动返回及中途取消。
- 注册 `kira://` 分享链接；HTTPS Universal Links 尚未配置（需要网站端关联文件）。
- 下载使用应用沙盒，开启了“文件”App 的文档共享；不要将备份或登录凭据存到 Documents。
- 漫画翻页模式的阅读设置提供“音量键翻页”开关并保存选择；音量+上一页，音量-下一页。
- 刷新率由 Flutter/iOS 自动管理；安卓的手动刷新率设置不适用于 iOS。
- iOS 没有 Android 前台下载服务，下载时保持应用在前台；后台持续下载尚未移植。
- 安装新版 IPA 仍需 AltStore 签名，不能使用 APK 更新器。
- Bundle ID 为 `io.github.reabin.kira`；更改它或签名账号可能导致安装为另一个应用。

## iOS 代理与测速

系统 HTTP 代理地址与 VPN 隧道是两种不同信息。iOS 未返回 HTTP 代理地址时，
应用展示“由 iOS 管理网络（VPN 状态无法确认）”，不会据此判断 VPN 未生效。
此更新不增加通用第三方 VPN 开关检测，也不根据虚拟网卡名称推断启用状态。
测速使用与应用请求相同的代理选择规则；系统模式下测速前刷新代理配置，
从其他应用返回网络设置页时刷新并重测，正在进行的旧测速完成后再启动新测速。
“直连”只绕过应用层 HTTP/SOCKS 代理，系统 VPN 仍可能处理连接。
每个节点连接探测总时限 5 秒，连接失败与超时返回不可达，不将未检测到代理作为失败条件。
测速测量连接建立耗时，不是下载带宽；实际是否经过 VPN 由系统和分流规则决定。

## 真机验收

首页轮播图位于最上方，“最近更新”位于其下。点击“关注地区”打开多选设置，
可组合选择日漫、韩漫、美漫，至少保留一项；勾选三项显示全部，默认日漫。
配置持久化并自动迁移旧版的日漫/全部选择，清理缓存不会删除配置。
“更多”打开共享相同筛选的完整列表，支持继续加载、下拉刷新与漫画详情跳转。
当前首页数据源（拷贝/热辣）的更新时间倒序保持不变，地区缺失时复用现有详情接口核实。
首页最多显示 12 部，每次加载最多扫描 5 页；分页保留整页结果与续读偏移，避免遗漏。
列表缓存 5 分钟，地区信息缓存 30 天，刷新会清除当前地区组合的各页列表缓存。

云端编译通过不等于真机验收通过。安装后检查首次启动、拷贝/热辣登录、
漫画翻页/缩放/亮度、轻小说阅读、下载与离线重启、相册保存、分享链接、
图标切换、备份导入导出。iPad 还应验证分享弹窗。

本地 Mac 构建：

```sh
flutter config --no-enable-swift-package-manager
flutter pub get
flutter build ios --release --no-codesign
```

## 最近更新加载与样式

地区过滤需要额外查询漫画详情，首次没有缓存时仍多于其他首页栏目的单次列表请求。
复用已打开漫画的详情缓存；核实任务使用最多4个持续工作槽，完成一个后补下一个，
不再等待每批全部结束。仅按已核实的连续前缀逐步展示，保持更新时间顺序。
首页先展示匹配当前来源和地区组合的最近快照（最多保留1小时），后台更新列表；
5分钟内的新鲜列表仍直接使用缓存。刷新时保留内容，失败显示重试入口。
拷贝首页最近更新复用其他栏目的折叠容器、两行漫画网格与更多样式；多选设置保留。

## iOS 音量键翻页

1.7.2+515 在漫画阅读设置的“翻页设置”中显示音量键翻页开关，仅翻页模式生效。
复用原有设置键，保留已保存的选择，关闭时恢复音量调节。
通过系统输出音量变化间接识别按键，阅读时保持进入时的音量，退出/暂停时恢复。
若进入时音量为0或接近最大值，会临时调整至可检测上下变化的范围。
仅在前台且阅读路由未被其他页面/弹层覆盖时监听；回到阅读页、解锁或音频中断结束时重新激活。
未启用后台音频；控制中心或其他来源的系统音量调整也可能被识别为翻页。

真机检查：开启后按音量+/音量-；切换应用和回桌面后返回；锁屏解锁；打开设置或评论弹层再关闭；
接听电话后返回；关闭开关确认音量正常调节；退出阅读器确认音量恢复；重启确认开关保留。
自动测试覆盖前后台、路由覆盖与返回、关闭开关、替换阅读器、失败重试和设置持久化。
系统音量变化和硬件按键仍需iPhone验证。
